# Selenium Automation Framework

A Java-based test automation framework for web, API, and PostgreSQL database testing. The framework will be developed on a dedicated feature branch.

## Planned technology stack

- Java 21
- Maven
- Selenium WebDriver (Chrome, Firefox, and Edge)
- TestNG
- REST Assured
- PostgreSQL JDBC
- Allure reporting
- Log4j2 logging

## Development

Framework implementation is maintained on `feature/enterprise-automation-framework` until it is reviewed and merged.
